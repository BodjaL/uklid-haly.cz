# Úklid haly

Statická prezentační stránka pro profesionální úklid průmyslových hal a skladů.

## Publikace na GitHub Pages

V nastavení repozitáře otevřete **Settings → Pages**, jako zdroj zvolte **Deploy from a branch**, větev `main` a složku `/ (root)`.

Před zveřejněním nahraďte ukázkový telefon a ověřte cílový e-mail formuláře v `index.html`.
